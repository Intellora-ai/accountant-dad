# ── WHY PADDLEOCR IS NOT IN THIS FILE ─────────────────────────────────────
#
# It cannot be. Its dependency tree is incompatible with two pins above, and CI
# proved it — `pip` returned ResolutionImpossible, measured, not predicted:
#
#     paddlex requires   numpy<2.4,>=1.24
#     this file pins     numpy==2.5.1
#
# and installing it also drags in `opencv-contrib-python 4.10.0.84` beside
# `opencv-python 5.0.0.93`. Both provide `cv2`, and install order decides which
# wins. Locally it was 4.10 that won, silently — `import cv2` reported 4.10.0
# while this file said 5.0.0.93.
#
# THAT MATTERS BECAUSE THE PINS CARRY MEASUREMENTS. `cleaner`'s deskew residual
# of 0.0017 at 32° was measured against opencv-python 5.0.0.93. Letting a
# transitive dependency of an OCR package silently replace the library the
# number was measured on would leave the assertion guarding a different library
# than the one it was derived from — the test would still pass and would no
# longer mean what it says.
#
# So the OCR stack moved to `requirements-engine1-ocr.txt`, which is exactly
# what TECHNOLOGY_STACK.md prescribes for engine dependencies. The cost is
# recorded honestly rather than hidden: reader's OCR tests do not run on CI
# until that manifest is installed there. See KNOWN_FAILURES.md F-002 and F-009.

# `transformers` for table structure. Both are locked choices, not preferences.

# Versions and licences read from installed metadata on 2026-08-05, never from
# memory. Every one of these is permissive — unlike pymupdf above, none of them
# raises a licensing question:
#
#   docling       2.118.0   MIT
#   transformers  5.8.1     Apache 2.0
#   torch         2.13.0    Apache-2.0 AND Apache-2.0 WITH LLVM-exception AND BSD
#   torchvision   0.28.0    BSD
#   timm          1.0.28    Apache-2.0
#   pypdfium2     5.12.1    BSD-3-Clause, Apache-2.0
#
# `timm` is not optional and its absence is not obvious. Without it the Table
# Transformer raises `ImportError: TimmBackbone requires the timm library`
# from deep inside `transformers`, and only one test catches it. Measured, not
# assumed: with timm absent, 50 of parser's 51 tests pass and the suite looks
# healthy.
#
# VERIFIED COMPATIBLE WITH THE PINS ABOVE. `pip install --dry-run` resolved
# clean, and after installing, `numpy.__version__` is still 2.5.1 and
